# Prácticas de Fundamentos de Programación

Este repositorio contiene mis prácticas del primer parcial usando PSeInt. 

Aquí aplico lógica de programación para resolver problemas paso a paso y entender el flujo de la información.

**Temas aplicados:**
- Asignación de variables.
- Condicionales (simples, anidadas y múltiples).
- Ciclos (Mientras).
- Subprocesos reutilizables.
